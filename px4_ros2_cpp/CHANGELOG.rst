Changelog for package px4_ros2_cpp
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

The version numbers of this package track the corresponding `PX4 Autopilot
<https://github.com/PX4/PX4-Autopilot>`_ release line rather than an
independent library semver. Starting with this entry the package is released
through the standard ROS 2 build-farm cycle, so the version recorded here is
authoritative and read by bloom at release time.

1.17.0 (2026-07-16)
-------------------
* Adopted the standard ROS 2 build-farm release cycle for the library.
* Aligned the package version to the PX4 Autopilot 1.17 release line.
* Packaging and release milestone only; the library is functionally unchanged.
