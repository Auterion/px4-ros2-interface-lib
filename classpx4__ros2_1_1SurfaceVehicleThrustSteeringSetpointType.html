Detailed Description

Setpoint type for surface vehicle thrust and steering control.

Can be used for surface vehicles, i.e. rovers and boats.

Send a thrust setpoint and a steering setpoint to the flight controller.

Parameters
thrust_body_x[-] Normalized thrust setpoint along body X axis. Takes values in [-1 (Backwards), 1 (Forwards)].
normalized_steering_setpoint[-] Ackermann: Normalized steering angle, Differential/Mecanum: Normalized speed difference between the left and right wheels. Takes values in [-1 (Left), 1 (Right)].
thrust_body_y[-] Normalized thrust setpoint along body Y axis (Optional, only relevant for omnidirectional vehicles, ignored by all other vehicles). Takes values in [-1 (Left), 1 (Right)].
